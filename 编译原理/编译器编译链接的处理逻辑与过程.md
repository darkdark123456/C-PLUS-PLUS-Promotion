**为什么重复的static 、 const 变量在多处定义是可行的？**
**两者的原理相同，这里仅以static为例子**

```cpp
//a.cpp
static int a=100;  //定义全局静态变量

//b.cpp
static int a=100; //定义全局静态变量


//编译通过 链接通过 
// static 全局变量 在语义分析阶段，编译器就确认了 Internal Linkage 内部链接，在obj文件中的存储类型会被标记为static，链接器不会对其进行全局符号解析，这个内部链接仅对该obj可见，所以每一个cpp源文件中的static全局变量仅对自己可见。所以即使两个全局static重名也不会出现链接错误。

```
