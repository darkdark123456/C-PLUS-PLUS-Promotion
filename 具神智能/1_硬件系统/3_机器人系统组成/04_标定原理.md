# 基础标定概念（Sensor Calibration Fundamentals）
## 什么是传感器标定（Calibration）
传感器标定（Calibration）是指通过实验测量和数学建模，建立**传感器输出数据与真实物理量之间准确对应关系**的过程。

由于实际传感器受到制造误差、安装误差、环境因素以及长期使用产生的偏差影响，其测量结果通常存在误差。因此，在机器人系统投入使用之前，需要通过标定确定传感器参数，并对测量数据进行修正。

简单来说：

**通过对测量值和真实值之间的关系分析，找到一种关联f函数，将来根据传感器的误差，反推真实值**

![image-20261114151612762](https://cdn.llfc.club/image-20261114151612762.png)

1. 相机光轴穿过物体，垂直正交情况，相机没有任何误差，物体成像应该落在照片的中心点，中线点就是主点(cx,cy)
2. 因为相机内部是有误差的，焦距在x轴，y轴都有分量，分别fx,fy,所以最后成像的点跑在了(ux,uy)

ux = fx *X/Z   + cx

uy = fy*Y/Z + cy

X是物体距离光心的x方向的位置， Y是物体距离光心y方向的位置， Z就是物体距离光心z方向的位置

这是无畸变情况下，得出的像素点的归一化的位置。

 fx *X/Z   这是缩放， +cx是平移。

3. 畸变就是相机镜头导致的，导致本应该是平面的图像变成了扭曲的。

成像的过程就是先进行上面的缩放，再平移，最后通过畸变参数产生即便模型，映射成新的图像。图像就产生了畸变。

所以相机内参有fx,fy,cx,cy, 还有几个畸变系数， k1,k2,k3,p1,p2 一起构成了畸变模型。



![image-20261114152631385](https://cdn.llfc.club/image-20261114152631385.png)



正向过程： 畸变过程，就是将真实的点，映射到正常图像(理想模型)找到ux,uv, 再通过畸变系数，计算最后畸变坐标。

方向计算： 拍摄得到畸变图片， 反向映射，得到一张理想的平面图。

![image-20261114153351560](https://cdn.llfc.club/image-20261114153351560.png)

``` python
import cv2
import numpy as np

# ====================== 1. 相机内参 & 畸变系数（对应你说的 fx,fy,cx,cy,k1,k2,p1,p2,k3） ======================
# 内参矩阵 K
# [[fx,  0, cx],
#  [0,  fy, cy],
#  [0,   0,  1]]
fx = 800.0
fy = 800.0
cx = 320.0
cy = 240.0
K = np.array([
    [fx, 0, cx],
    [0, fy, cy],
    [0, 0, 1]
], dtype=np.float64)

# 畸变系数 dist = [k1, k2, p1, p2, k3]
# 顺序固定！OpenCV 标准顺序：径向k1,k2，切向p1,p2，径向k3
k1 = -0.2
k2 = 0.1
p1 = 0.001
p2 = -0.0005
k3 = 0.05
dist = np.array([k1, k2, p1, p2, k3], dtype=np.float64)


# ====================== 2. 读取畸变原图 ======================
img = cv2.imread("distorted.jpg")
h, w = img.shape[:2]

# ====================== 3. undistort 去畸变核心 ======================
# newCameraMatrix：可选，控制校正后画面FOV；如果和K一致，会保留原图视野，边缘会有黑边
new_K, roi = cv2.getOptimalNewCameraMatrix(K, dist, (w, h), alpha=1, newImgSize=(w, h))

# 去畸变主函数
img_undist = cv2.undistort(img, K, dist, None, new_K)

# roi 是有效区域（去掉黑边），可选裁剪
x, y, roi_w, roi_h = roi
img_undist_crop = img_undist[y:y+roi_h, x:x+roi_w]


# ====================== 4. 展示、保存 ======================
cv2.imshow("distorted original", img)
cv2.imshow("undistorted full (with black border)", img_undist)
cv2.imshow("undistorted cropped", img_undist_crop)

cv2.imwrite("undistorted_full.jpg", img_undist)
cv2.imwrite("undistorted_crop.jpg", img_undist_crop)

cv2.waitKey(0)
cv2.destroyAllWindows()

```

### 镜头畸变参数（Lens Distortion）
实际镜头无法完全满足理想针孔模型，会产生：

+ 径向畸变（Radial Distortion）
+ 切向畸变（Tangential Distortion）

例如：

<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/27211935/1790044353258-3a6e054c-b700-45c3-9a6a-e909af0155c4.png)

**总结：**

fx 表示 相机在x轴分量的焦距

fy表示相机在y轴分量的焦距

X,Y,Z这是已知的物体在三位空间的坐标

cx,cy 主点可以通过相机的光轴和成像后的中心点确定，u,v观测实际物体成像坐标。

相机内参用于：

+ 图像畸变校正
+ 视觉测距
+ 三维重建
+ 视觉 SLAM
+ 目标定位

常用方法：

+ 棋盘格标定板
+ AprilTag 标定板
+ 张正友标定法（Zhang Calibration）

### 总结
传感器标定是机器人系统建立准确感知能力的基础，其核心目标是：

**确定传感器参数，并建立不同传感器之间准确的空间关系。**

主要标定类型：

| 标定类型 | 主要作用 |
| --- | --- |
| 相机内参标定 | 校正相机成像模型 |
| 相机外参标定 | 建立相机与机器人坐标关系 |
| 手眼标定 | 建立机械臂与相机关系 |
| LiDAR-相机标定 | 实现图像与点云融合 |
| IMU标定 | 提高姿态估计精度 |


完成标定后，机器人能够在统一时间和空间坐标框架下融合多源信息，为 **SLAM、导航、目标识别、机器人操作以及具身智能系统中的感知与决策** 提供可靠的数据基础。
