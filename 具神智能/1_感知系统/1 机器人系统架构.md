# 机器人硬件整体组成
1. **机械结构本体**：底座、连杆（Link）、关节壳体、末端法兰。
2. **执行与传动系统**：电机、减速器、制动器、编码器。
3. **感知系统**：IMU、力 / 力矩传感器、相机、激光雷达、接近传感器等。
4. **控制系统硬件**：运动控制器（从站）、主控制器（主站）、工控机 / 嵌入式板。
5. **电源与配电系统**：电池 / 电源模块、稳压电路、急停回路。
6. **通信与布线**：总线（CAN / EtherCAT）、线缆、滑环、走线通道。
7. **末端执行器（End-effector）**：夹爪、吸盘、灵巧手、工具快换装置。
8. **安全与辅助组件**：急停按钮、安全继电器、限位开关、散热结构、防护外壳。

# 机器人的核心硬件


**机器人硬件核心主要包括四大部分：执行系统、感知系统、通信系统和末端执行系统。**

+ **一体化关节模组（执行系统）**：负责产生运动，是机器人的动力来源。
+ **感知系统（Sensing）**：负责获取机器人自身状态及外部环境信息。
+ **通信与布线系统（Communication）**：负责控制器、关节和传感器之间的数据传输。
+ **末端执行器（End-effector）**：直接与环境交互，完成抓取、装配、焊接等任务。



# 什么是一体化关节


**一体化关节（Integrated Joint Module）** 是一种将机器人关节所需的多个核心部件集成在同一个壳体内的模块化执行单元，通常包括**电机、减速器、编码器、驱动器以及通信接口**等部件，可直接作为机器人的一个运动关节使用。

一句话理解：

**一体化关节就是把"电机+减速器+编码器+驱动器+通信"集成在一个模块里，通电即可作为机器人关节使用。**

## 为什么机器人越来越多采用一体化关节
相比传统分体式方案，一体化关节具有以下优势：

+ **高度集成**：减少机械装配和布线工作。
+ **安装方便**：模块化设计，便于快速搭建机器人。
+ **控制简单**：通常内置位置、速度、力矩等控制模式。
+ **可靠性高**：内部结构经过优化，抗振动和抗干扰能力更强。
+ **维护方便**：出现故障时，可直接更换整个关节模块。
+ **易于扩展**：多个关节通过总线即可组成多自由度机器人。

## 一体化模组常见应用
目前，一体化关节已经成为机器人执行系统的主流方案，广泛应用于：

+ **协作机械臂**
+ **工业机器人**
+ **四足机器人**
+ **人形机器人**
+ **外骨骼机器人**
+ **服务机器人**

例如，课程中使用的 **飞特 STS3215 总线舵机** 就可以视为一种**轻量级一体化关节模组**：它将电机、减速器、磁编码器、驱动电路和 TTL 总线通信接口集成在一个紧凑的外壳内，能够完成位置控制并实时反馈关节状态，非常适合作为机器人硬件学习。
