# 电机（Motor，致动器）
## 作用
电机是机器人的**动力来源**，负责将电能转换为机械能，驱动机器人关节旋转，因此也称为**致动器（Actuator）**。

## 工作原理
驱动器根据控制指令向电机输出电流，电机内部产生电磁转矩，带动转子旋转。

## 电机参数
| 参数 | 含义 | 简单理解 |
| --- | --- | --- |
| **额定功率（W）** | 电机长期稳定工作的输出功率 | 电机持续能提供多大动力 |
| **额定电压（V）** | 电机正常工作的供电电压 | 电机需要多少电压才能正常运行 |
| **最大转速（rpm）** | 电机允许达到的最高转速 | 电机最快能转多快 |
| **额定转矩（Nm）** | 电机长期连续输出的旋转力 | 电机平时能稳定拧多大力量 |
| **峰值转矩（Nm）** | 电机短时间能够输出的最大力量 | 电机瞬间爆发能力 |


## 电机类型


+ 有刷直流电机（DC Motor）
+ 无刷直流电机（BLDC）
+  有刷直流电机（DC Motor）  
+ 永磁同步电机（PMSM，机器人最常见）
+ 步进电机（Stepper）



**几种电机对比**

| 电机类型 | 工作特点 | 优点 | 缺点 | 典型应用 |
| --- | --- | --- | --- | --- |
| **有刷直流电机（DC Motor）** | 通过电刷和换向器实现电流换向 | 结构简单、成本低、控制容易、启动转矩大 | 电刷磨损、寿命较短、有火花、电磁干扰较大、高速性能一般 | 玩具机器人、小型执行机构、电动车、低成本设备 |
| **无刷直流电机（BLDC）** | 使用电子换向代替机械电刷，通过控制三相电流产生旋转磁场 | 效率高、寿命长、转速高、可靠性好、维护少 | 需要专用驱动器、控制复杂、成本较高 | 无人机、云台、机器人关节、电动车 |
| **永磁同步电机（PMSM）** | 永磁转子与旋转磁场同步运行，通常采用FOC控制 | 转矩密度高、效率高、运行平稳、精度高、低噪声，适合闭环控制 | 成本较高、需要高性能驱动器、控制算法复杂 | 工业机器人、协作机器人、人形机器人、高性能伺服关节 |
| **步进电机（Stepper）** | 根据脉冲信号按固定角度一步一步运动 | 控制简单、定位方便、成本低、低速保持力矩大 | 容易丢步、高速转矩下降、效率低、发热明显 | 3D打印机、CNC、小型机械臂、定位平台 |




**从机器人角度选择**

| 关注点 | 最适合电机 |
| --- | --- |
| 低成本、简单运动 | 有刷直流电机 |
| 高速、高效率 | BLDC |
| 高精度机器人关节 | PMSM ⭐ |
| 简单定位控制 | 步进电机 |




##  有刷直流电机（DC Motor）
### **定义**
有刷直流电机是一种利用**电刷和换向器**实现电流换向的电机，通过改变电流方向产生持续旋转。

### 工作原理
 换向器不断改变电流方向，使电机持续转动。

## 无刷直流电机（BLDC）
### 定义
无刷直流电机取消了电刷和换向器，通过**电子换向控制器**控制电流方向。

### 工作原理
:::warning
它通过驱动器控制定子线圈中的电流变化，产生**旋转磁场**，带动永磁转子旋转，实现电能到机械能的转换。

简单理解：

**控制器不断改变线圈电流方向 → 产生旋转磁场 → 永磁转子跟随磁场旋转 → 输出机械运动。**

:::



<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2026/png/27211935/1789556437524-9fb2c4f3-5cf1-40d5-9a0b-6924fab51132.png)

###  应用
大量用于：

:::warning
+ 无人机
+ 云台
+ 机器人关节
+ 电动车
+ 风机

:::

>  无刷直流电机通过电子驱动器控制三相绕组电流，产生旋转磁场，使永磁转子跟随磁场运动，从而实现电能到机械能的转换。相比有刷电机，BLDC具有高效率、高可靠性和长寿命等特点，是机器人关节和一体化执行器中常用的动力来源。

###  与 BLDC 的区别
两者很像：

| | BLDC | PMSM |
| --- | --- | --- |
| 反电动势 | 梯形波 | 正弦波 |
| 控制方式 | 六步换向 | FOC控制 |
| 平稳性 | 一般 | 更好 |
| 噪声 | 较高 | 更低 |
| 精度 | 较低 | 更高 |




### 优点
高效率  
转矩密度高  
运行平稳  
精度高  
适合闭环控制



###  应用
机器人领域最常见：

+ 工业机械臂
+ 协作机器人
+ 四足机器人
+ 人形机器人
+ 伺服关节

# 步进电机（Stepper Motor）
##  定义
步进电机是一种根据输入脉冲信号，使转子按照固定角度一步一步旋转的电机。

## 工作原理
控制器输出脉冲：

通过控制脉冲数量控制位置。

效率较低  
发热明显
